2. The product

The Report is a multi-page PDF document, and a web page with the same content, for a single United States street address that you supply. It is composed from publicly available federal and state databases (including those maintained by the EPA, FEMA, USGS, USFWS, USFS, EIA, NPS, NOAA, FAA, the US Census Bureau and state geological surveys and air agencies) and from mapping services, within defined search radii around the geocoded location of the address. The sections, sources, radii, retrieval dates and data vintages are stated inside each Report on its method page and in the collar of each map.

The Report is deterministic: for a given address and a given state of the source databases, the same inputs produce the same Report. Values in the Report are read from source records and attributed to them. The Report's section levels (Low, Moderate, Elevated, High, Severe, Not screened) and its composite score are relative screening indicators derived from proximity, designation and regulatory status as recorded in those sources, by weights and thresholds printed in the Report.

7. Checks status and disclosed gaps

Each Report prints a checks status on its cover. "Checks: passed" means every core source returned, every figure reconciled to its source record, and every cross-check passed. "Checks: flagged" means at least one source did not return or at least one check did not pass. A flagged Report marks each affected section as "Not screened," lists the affected sources on its method page, and is otherwise complete. The checks status is a retrieval and consistency check of our transcription; it is not a verification of the underlying public records.
